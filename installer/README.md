# Сборка установщика InkFlow

## Что нужно один раз установить

- Flutter SDK (уже есть).
- [Inno Setup 6](https://jrsoftware.org/isinfo.php). Через winget:

```powershell
winget install -e --id JRSoftware.InnoSetup
```

После установки `ISCC.exe` обычно находится в
`%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe`.

## Как собрать установщик

1. Поднимите версию в `pubspec.yaml`. Например:

```yaml
version: 1.0.1+2
```

Число до `+` — версия приложения (по ней приложение понимает, что вышла
новая версия),
число после `+` — build number.

2. Запустите из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_installer.ps1
```

Скрипт сам:

- соберёт `flutter build windows --release`;
- прочитает версию из `pubspec.yaml`;
- создаст установщик через Inno Setup.

Готовый файл появится здесь:

```
dist\InkFlow-Setup-<версия>.exe
```

Если релиз уже собран и нужно только пересобрать установщик:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_installer.ps1 -SkipBuild
```

## Как выложить обновление на GitHub

Важно: проверка обновлений смотрит на **последний опубликованный релиз**
(`/releases/latest`), поэтому релиз не должен быть черновиком или
pre-release.

Через GitHub CLI:

```powershell
git tag v1.0.1
git push origin v1.0.1
gh release create v1.0.1 "dist\InkFlow-Setup-1.0.1.exe" `
  --title "InkFlow v1.0.1" `
  --notes "Что изменилось: ..."
```

Через сайт GitHub:

1. Releases → Draft a new release.
2. Tag: `v1.0.1` (тег должен совпадать с версией из `pubspec.yaml`).
3. Прикрепите `InkFlow-Setup-1.0.1.exe` как asset.
4. Опубликуйте релиз.

Требования к asset:

- расширение `.exe`;
- имя может быть любым, но удобно `InkFlow-Setup-<версия>.exe`.

## Как работает обновление внутри приложения

При запуске приложение проверяет последний релиз через GitHub API. Если
доступна новая версия, появляется предупреждение с описанием релиза.

Кнопки в окне:

- «Скачать обновление» — открывает в браузере файл установщика из релиза,
  и начинается обычное скачивание.
- «Открыть на GitHub» — открывает страницу релиза.
- «Позже» — закрывает окно. При следующем запуске оно не появится снова
  для этой же версии, но обновление останется в
  **Настройки → Обновления**, откуда его можно скачать в любой момент.

После скачивания запустите `InkFlow-Setup-<версия>.exe` и установите
обновление поверх текущей версии. Приложение не скачивает и не запускает
установщик само.

Установка идёт в пользовательскую папку:

```
%LOCALAPPDATA%\Programs\InkFlow
```

Поэтому обновление не требует прав администратора и UAC.

## Ограничения и рекомендации

- На целевой машине нужен **Microsoft Visual C++ Redistributable 2015–2022
  (x64)**. На Windows 10/11 он обычно уже установлен; если приложение
  не запускается с ошибкой о `VCRUNTIME140.dll`, установите его.
- Репозиторий должен быть публичным: GitHub API без токена не отдаст
  релизы приватного репозитория.
- Без токена лимит GitHub API — 60 запросов в час с одного IP.
  Приложение делает одну проверку при запуске и ещё одну при ручной
  проверке в настройках, так что лимита с запасом хватает.
- Для распространения в интернете подпишите `.exe` и установщик
  сертификатом Code Signing, иначе Windows SmartScreen будет
  показывать предупреждение.
- Если приложение запущено не из установленной версии (например,
  `flutter run`), при обновлении браузер всё равно скачает релизный
  установщик, а он поставит копию в
  `%LOCALAPPDATA%\Programs\InkFlow`. Это нормально для тестов.
- Пользовательские данные (Hive, аудио, вложения) хранятся в папке
  поддержки приложения и при обновлении/удалении не затрагиваются.
